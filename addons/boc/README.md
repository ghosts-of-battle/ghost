ghost_boc
=========

Backpack On Chest Redux, bundled into Ghosts of Battle.

Ports [BackpackOnChestRedux](https://github.com/mjc4wilton/BackpackOnChestRedux)
(by DerZade & mjc4wilton) into the ghost namespace: prefix `z\ghost\addons\boc`,
runtime functions `ghost_boc_fnc_*`, CBA settings `ghost_boc_*`. The legacy
`zade_boc_fnc_*` public API is preserved via `fnc_legacyRedirect`.
